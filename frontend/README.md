# Oráculo Vida Web

Frontend independente do Oráculo Vida, criado com React, TypeScript e Vite.

## Executar

```bash
npm install
npm run dev
```

## Validar

```bash
npm run build
```

## Estado

- Duas identidades visuais: Casa de Maria Padilha e Caminhos do Axé.
- Onboarding com múltiplos interesses, persistidos apenas no navegador.
- Navegação responsiva por catálogo, módulos, perfil e configurações.
- Módulos ainda em desenvolvimento identificados explicitamente; sem consultas, autenticação, pagamento ou integração Gemini reais.
- Arquivos da versão HTML/CSS/JS anterior preservados em `legacy/`.
- Backend: https://github.com/FELIPECOXTA/Oraculo-vida
- Nenhuma infraestrutura Azure necessária para desenvolvimento local.

## Pendências

Integração com backend seguro, autenticação, cálculos, conteúdo validado, consultas humanas, pagamento, testes e deploy. Nunca colocar chaves privadas em variáveis `VITE_*`.
